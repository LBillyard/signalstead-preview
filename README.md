# Streaming apps for a Windows laptop

Quick links for installing or opening seven streaming services on a Windows 10/11 laptop.

| Service | Windows download / access |
| --- | --- |
| Disney+ | [Install from Microsoft Store](https://apps.microsoft.com/detail/9nxqxxlfst89) |
| Netflix | [Install from Microsoft Store](https://apps.microsoft.com/detail/9wzdncrfj3tj) |
| BBC iPlayer | [Open BBC iPlayer](https://www.bbc.co.uk/iplayer) |
| ITVX | [Open ITVX](https://www.itv.com/watch) |
| Channel 4 | [Open Channel 4](https://www.channel4.com/) |
| Paramount+ | [Install from Microsoft Store](https://apps.microsoft.com/detail/9wzdncrfj0wk) |
| Sky Go | [Download official Windows installer](https://www.sky.com/watch/sky-go/windows) |

**Tip:** To make a website behave like a standalone desktop app, open the website in Microsoft Edge, select **... > Apps > Install this site as an app**.

The BBC iPlayer, ITVX and Channel 4 links open their websites, rather than downloading Windows installers.
